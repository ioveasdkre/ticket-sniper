「搶票助手 Pro」是 Chrome Extension，同時支援 KKTIX、Tixcraft、TicketPlus、inline.app、momoshop 五個站台。設計理念：一個側邊面板 popup.html, popup.js；kktix/tixcraft/ticketplus/inline/momoshop-content.js 各一支 content script；background.js service worker 負責頁面重載後的恢復。

核心機制:
- globalEnabled toggle(全域開關)控制所有內容腳本注入，popup.js共用 toast/showToast/kktixAddLog/tcAddLog/tpAddLog/inAddLog/momoAddLog 等日誌函式族。
- background.js在changeInfo.status==="loading"/"complete"時偵測 URL 模式(KKTIX_PATTERN/TIXCRAFT_PATTERN/TICKETPLUS_PATTERN/INLINE_PATTERN/MOMOSHOP_PATTERN),並依 PLATFORM_REINJECTION_RULES 宣告式規則表自動重新注入腳本 + 送出 START。momoshop 是例外，以 momoshop_tabSessions 做每分頁獨立管理。
- shared.js 的 createContentController 提供統一的 START/STOP/updateGlobalEnabled 訊息處理、runToken 防陳舊執行、storage 自動恢復；tixcraft/ticketplus/momoshop 使用此工廠，kktix/inline 仍是手寫版本。
- tixcraft-content.js透過 chrome.runtime.sendMessage{action:"OCR_REQUEST"}呼叫 background 代理 HTTP 到本機 ocr_server.py,繞過 HTTPS->HTTP fetch mixed content restriction。TicketPlus 不使用 OCR。
- Discord webhook notification在到達 checkout/verify/confirm 頁時送出通知 (各平台各自有 webhook URL；ticketplus 目前留空未設定)。

TicketPlus 模組特殊性:
- ticketplus/ticketplus-content.js 是 E:\project\ticketsystem\chrome_tixcraft.py 中 ticketplus 段(L9889-11293)的逐行移植，每個函式都標註對應的 Python 行號。
- ticketplus.com.tw 是 Vue(Vuetify 2) SPA，URL 會在不重新載入的情況下改變，因此 content script 採用 **每 50ms 一輪的輪詢主迴圈**（對應 Python main() 的 while True + sleep(0.05)），而非其他平台的「一次頁面載入跑一次」。
- 未開賣自動重整由擴充功能負責：從 performance.getEntriesByType("resource") 找出頁面打過的 apis.ticketplus.com.tw/config/api/...get?productId= 網址，重新 fetch，result.product[0].status === "pending" 就 reload。Python 端在 advanced.chrome_extension 為 true 時會刻意略過這段，註解寫明「move below code to chrome extension」。
- 未移植：OCR 驗證碼(Python 中為死碼)、自動登入、util.get_answer_list_from_question_string 大型題目解析器、線上答案檔。
